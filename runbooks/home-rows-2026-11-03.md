# Home rows from 2026-11-03

The owner asked for these Home rows on 2026-11-03, using their Plex Home as the model. Each row
holds up to 25 titles:

| Row (kicker / title) | Replaces | Source |
| --- | --- | --- |
| RECENTLY ADDED / MOVIES | Recently Added Movies and TV Shows | The app: the Movies library's newest titles (Jellyfin latest media), up to the member's Home row length (default 25) |
| RECENTLY ADDED / TV SHOWS | (the same combined row) | The app: the TV Shows library's newest titles, as above |
| TRENDING / MOVIES | Movies Top of the Charts | The server's "Trending Movies" smart collection: TMDB's daily trending movies |
| TRENDING / TV SHOWS | TV Shows Top of the Charts | The server's "Trending TV" smart collection: TMDB's daily trending shows |
| 90 DAYS / RECENTLY RELEASED | Popular Movies & TV Shows | The server's "Recently Released - 90 Days" smart collection: movies released in the last 90 days, newest first |
| MOVIE / ROULETTE | Trending Movies & TV Shows | The server's "Movie Roulette" smart collection: 30 random movies, picked again each day |

Top 10 Movies This Week and Top 10 TV Shows This Week are gone.

## How the server rows get to the TV

- The SmartLists plugin on Jellyfin refreshes the four collections once a day, between 05:01 and
  06:51. They are the same collections members see in Collections → New & Trending.
- `justwatch-home.sh` on Unraid runs every 10 minutes and reads each collection's movies or shows
  in the collection's own order, up to 50 of them. It saves them in every member's display
  preferences (id `justwatch-home`, client `WeaselPlex`) as `trending_movies`, `trending_shows`,
  `recently_released` and `movie_roulette`.
- The app (`JustWatchRowService`) fetches those IDs as the member, so titles a member can't see
  drop out, and shows the first 25.
- A collection that can't be read, or is empty, keeps its last list, and the script logs it in
  `justwatch-home/run.log`.
- The script is not in git. Its backup from before this change is
  `/mnt/cache/appdata/_dacrib-scripts/justwatch-home.sh.bak-2026-11-03-collections`.
- To change what a row holds, edit the smart collection on Jellyfin (SmartLists), not the app.
  If you rename a collection, update `COLLECTION_LISTS` in the script.

## Older apps

TV v1.2.43 and earlier, and the phone app, still read `movie_chart`, `show_chart`, `popular`,
`trending`, `top_10_movies` and `top_10_shows`, so the script keeps making them. Remove them
from its `LISTS` only once no supported app reads them.

Saved Home layouts move to the new rows once: `ApprovedHomeLayout.REVISION` 16 rearranges them
through `WeaselHomeRows.arrange`. A saved row for one of the old lists no longer decodes and is
dropped.
